## 👋 About Me

Hi, I'm **Tanishq**. I'm a builder who learns by making things. I'm curious about how artificial intelligence really works, not just how to use it, and I'm working towards a career where I can make my own games.

Right now my time goes into two big areas:

1. **Fine-tuning large language models (LLMs)**: taking existing models and teaching them new behaviors or styles.
2. **Learning game development**: studying game engines and programming so I can build and ship real games.

I also build practical software projects along the way, because making real things teaches me faster than just reading about them.

This profile is a fresh start for me. I'm using it to document what I build, what I learn, and where I'm headed.

## 🔬 What I Work On

### 🤖 Fine-tuning language models

I experiment with taking pre-trained language models and adapting them for specific tasks. I'm learning how this works from the ground up:

- how language models are structured (transformers)
- how efficient fine-tuning methods like **PEFT** reduce the compute needed
- how to prepare and clean training data
- how to evaluate whether a fine-tuned model is actually better
- how to run training and inference on Apple Silicon with **MLX**

### 🎮 Game development

I want to become a game developer, so I'm learning the tools and skills games are built from:

- **Godot** and **Unity**, the engines I'm exploring
- **C#** and **C++**, the main languages behind game development
- game design basics: loops, mechanics, level design, and player feedback
- turning small game ideas into finished, playable prototypes

### 📱 Software projects

I build real apps to practice clean code, project structure, and shipping. My current big project is below.

## 🎧 Current Project

### [Adless Streaming](https://github.com/ushin-git/adless-streaming)

An **Android music player** I'm building that is ad-free and privacy-focused.

- 🚫 No ads, trackers, analytics, or required accounts
- 🔌 Music sources are **pluggable modules**, so new ones can be added without touching the UI
- 🏷️ Every track shows its source and license information
- 🧪 Currently in **public alpha**, so it's early and still growing

I'm building it to learn Android development, clean architecture, and how to ship a real project honestly, including being clear about what isn't finished yet.

## 🌱 How I Learn

1. **Pick a small, real project.** Learning sticks when I'm building something I care about.
2. **Break it into steps.** Big ideas become small tasks.
3. **Use tools wisely.** I use AI assistants to speed things up, but I read, test, and understand what they produce.
4. **Ship, then improve.** A working rough version beats a perfect idea that never exists.
5. **Write it down.** Documenting what I did helps me remember it and helps others.
